📐 Unit 7 — Exponential & Logarithmic Functions

Growth/decay, e, logs, log properties, and solving. Pass the test to unlock Unit 8.
Exponential: y = a·bˣ. b > 1 → growth · 0 < b < 1 → decay. e ≈ 2.718 (continuous growth).
Log ↔ exponent: log_b(x) = y means bʸ = x. So log₂8 = 3 because 2³ = 8. (ln = log base e.)
log_b(1) = 0 · log_b(b) = 1
Properties: log(xy)=log x+log y · log(x/y)=log x−log y · log(xⁿ)=n·log x
Change of base: log_b(x) = (log x)/(log b).
