📐 Unit 5 — Rational Functions

Asymptotes, intercepts, operations, and solving (watch for extraneous!). Pass the test to unlock Unit 6.
Vertical asymptote: set the denominator = 0.
Horizontal asymptote: deg(top) < deg(bottom) → y = 0 · equal degrees → y = (ratio of leading coeffs) · top bigger → none.
Form a/(x−h) + k: VA x = h, HA y = k.
x-int: numerator = 0 · y-int: plug in x = 0 · domain: all reals except the VA.
Solving: cross-multiply or clear with the LCD. Extraneous: any answer that makes an original denominator = 0 → reject it.
