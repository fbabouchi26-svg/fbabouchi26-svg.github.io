📐 Unit 2 — Quadratic Functions

Parabolas: forms, vertex & axis, transformations, and modeling. Pass the test to unlock Unit 3.
Vertex form: y = a(x − h)² + k → vertex (h, k), axis x = h
Standard form: y = ax² + bx + c → axis x = −b/2a (plug in for the vertex y), y-int = c
Intercept form: y = a(x − p)(x − q) → x-ints p, q, axis x = (p+q)/2
a > 0 opens up (minimum) · a < 0 opens down (maximum) · |a|>1 stretch, |a|<1 shrink · −a flips over x-axis
